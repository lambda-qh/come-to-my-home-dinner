# 来我家吃饭吧 · 微信小程序

记录你的拿手菜，生成带热度标签的私房菜单，一键产出"想吃视角"愿望海报分享给朋友。

## 功能一览

- **菜品管理**：作者可发布新菜品，配置菜名、**一句话描述**（仿宋斜体引号展示于菜名与食材之间）、**自定义标签**（如"春季限定""减脂福音"）、主要食材、图片（拍照 / 相册上传）；编辑与删除统一在「管理」后台操作
- **菜单分组浏览**：菜单页采用**左侧分类侧边栏 + 右侧菜品列表**布局（外卖点餐式），侧边栏列出"全部 + 各自定义标签"，点击即筛选该分组菜品，右侧顶部可切换 默认 / 评分榜 / 人气榜 排序
- **打分评价**：星级评分（1–5 星）+ 文字评价 + **最多上传 4 张图片**（拍照 / 相册），自动累计均分与评价列表
- **想吃清单**：收藏想吃的菜，支持单条移出、**多选生成海报**（只含勾选菜品）
- **愿望海报（点单视角）**：Canvas 2D 生成"想吃清单 · 请主厨安排"风格海报，可**一键转发厨子**（进入主理人收件箱）或保存到相册
- **点单私信**（主理人收件箱）：接收来自想吃清单的转发消息，含海报缩略图、菜品、时间与未读标记，支持查看与删除
- **饭局**：主理人可创建饭局（名称 / 日期 / 备注），一键生成饭局邀请海报分享；朋友从海报进入即向这场饭局点单
- **作者管理后台**（「管理」Tab，仅主理人可见）：菜品数据明细（编辑 / 删除）、点单私信收件箱、饭局管理、数据重置与清空
- **热度标签**：根据评分、点单、收藏、上新时间自动生成（卡片最多 1 条，避免拥挤）：
  - 本店推荐 Top1（全菜单评分榜首）
  - 好评如潮 4.8 分 / 口碑不错 4.3 分
  - 近7天 N 人点单（打开详情页计一次点单）
  - N 人想吃（收藏热度）
  - 新菜尝鲜（7 天内添加）
- **榜单排序**：默认 / 评分榜 / 人气榜（近 7 天点单）

## UI 设计

参考 Claude 设计语言 + 性冷淡克制原则：暖米白底色（#FAF9F5）、墨色文字（#3D3929）、大圆角白卡配柔和阴影与淡边框、珊瑚橙（#DA7756）仅用于评分与 Top1 标签点缀；无 emoji、无重色块，菜品无图时以菜名首字占位。海报与页面风格统一。

## 页面结构

```
pages/
  index/     菜单列表（热度标签 + 榜单）
  edit/      添加 / 编辑菜品
  detail/    菜品详情（打分、评价、收藏、海报入口）
  wishlist/  想吃清单
  poster/    愿望海报（Canvas 2D + 保存相册）
  profile/   管理后台（发布入口 + 评价/收藏/点单数据明细）
utils/
  store.js      数据层（本地缓存，内置示例菜品）
  hot-tags.js   热度标签引擎
  poster.js     海报绘制
components/
  dish-card/    菜品卡片
  star-rating/  星级评分
```

## 运行方式

1. 打开 **微信开发者工具** → 导入项目，选择本目录
2. 当前 `project.config.json` 使用 `touristappid`（游客模式），可直接预览；正式使用请在开发者工具中换成你自己的小程序 AppID
3. 编译后在模拟器中即可体验；真机预览可测试拍照上传与保存海报到相册

## 数据说明

- 所有数据保存在微信本地缓存（`wx.Storage`），不涉及服务器，换设备不共享
- 首次启动内置 6 道示例菜（含预置评分、评价与点单数据），方便直接体验热度标签效果
- 数据可在「管理」页重置为示例数据或清空

## 权限说明

保存海报到相册需要 `scope.writePhotosAlbum` 授权，拒绝授权时会引导到设置页开启。
